# Product Strategy

Active product direction:

- `macos-live-island/` - native macOS live activity island inspired by Alcove, starting with a cleaner and cheaper music-first MVP.
- `government-construction-management/` - mobile-first project management for government construction engineers, contractors, and site supervisors.

Archived or rejected directions:

- Laundry and cleaning-service marketplace - rejected during the 2026-05-26 pivot meeting in favor of the government construction product.

## Current Focus

The current product focus is `macos-live-island/`. The next implementation step is validating macOS media metadata APIs and scaffolding a native SwiftUI/AppKit prototype for the floating island shell.
