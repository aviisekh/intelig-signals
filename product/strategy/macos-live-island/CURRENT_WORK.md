# Current Work

## Active Goal

Build the first usable prototype of a native macOS live activity island inspired by Alcove, with a cheaper, cleaner, music-first product direction.

## This Week

- Confirm target macOS version and minimum hardware expectations.
- Validate access to current media metadata and playback controls.
- Create ADR-0001 for native SwiftUI/AppKit architecture.
- Create ADR-0002 for music metadata and fallback strategy.
- Scaffold the macOS app project.
- Build a top-center borderless floating window prototype.
- Implement compact and expanded island states with static mock music data.

## Next Decisions

- Product name.
- Minimum supported macOS version.
- Initial price point inside the USD 4.99 to USD 9.99 range.
- Trial model: time-limited trial, free limited mode, or pay-what-you-want early access.
- Whether to ship outside the Mac App Store first for faster iteration.

## Open Questions

- Which music sources must work on day one: Apple Music, Spotify, browser playback, or all system Now Playing sources?
- Should the island be notch-attached only, or support non-notch Macs as a floating island from day one?
- Should the first version include a menu bar icon, settings window, or both?
- Should AirDrop be the second module, or should downloads/timers come first because they are easier to control reliably?

## Done

- Created Mission, Vision, PRD, Design, Architecture, Implementation Plan, Status, and Competitive Positioning documents.
- Positioned Alcove as the primary inspiration and quality bar.
- Defined the initial wedge: cheaper, cleaner, music-first, rich animation, low-resource, extension-ready.
